🎬 Filmalisa

Modern Movie Platform – Admin Panel & User Interface

Filmalisa is a full-stack movie platform where users can explore movies, and admins can manage content through a powerful dashboard.

---------------------------------------------------------------------------------------

🚀 Project Overview

Filmalisa consists of:
🎥 Movie management system
👤 User management
🏷 Category system
💬 Comment moderation
📩 Contact management
🔐 Secure admin panel
